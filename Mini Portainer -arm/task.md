### 项目二：跨设备轻量级容器管理面板 (Mini Portainer)

如果你在不同的机器上跑了许多 Docker 容器，这个项目能让你告别繁琐的 SSH 登录，在一个页面掌控全局。

* **云服务器（中央调度大脑 & 面板 UI）**
* **核心功能：** API 网关与前端面板的宿主机。
* **具体动作：** 运行主 Go Server，提供完整的 RESTful API。它维护着一个设备列表（Windows, 树莓派等）。不仅负责将各个节点上报的容器状态汇总展示在 Web 页面上，还能通过 WebSocket 与各个节点保持长连接。当你点击页面上的“查看日志”时，云服务器会把请求转发给对应节点，并将日志流实时传回浏览器。


* **树莓派 3B / 老旧 x86 主机（边缘执行节点）**
* **核心功能：** 容器探针与指令执行器。
* **具体动作：** 这些机器上运行着跨平台编译的 Go Agent 二进制文件。Agent 通过调用本机的 Docker Socket (Docker API)，实时读取容器的 CPU/内存占用率、运行状态。如果云服务器下发了“重启容器”或“拉取新镜像”的指令，Agent 会在本地执行该动作并反馈结果。


* **Windows 电脑（控制台客户端）**
* **核心功能：** 你的超级管理员终端。
* **具体动作：** 作为日常使用的机器，你只需要打开浏览器，访问云服务器提供的管理面板，就能直观地看到树莓派和 x86 实验机上的 Docker 运行情况，并进行一键启停等操作。
